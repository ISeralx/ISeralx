# Hi, I'm Alejandro 👋

**Physicist → Quantitative Research & Trading.** I came to markets by *building*: capturing data,
finding a real edge, and validating it honestly — out-of-sample, net of costs, with no look-ahead.

I care about **structural edges** (mechanical mispricings you can reason about) more than fitted
signals, and I like turning a messy question into a reproducible result.
